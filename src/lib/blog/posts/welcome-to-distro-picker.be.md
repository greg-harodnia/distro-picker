# Вітаем у Выбарніку Дыстрыбуцыі

Ня ведаеце, якую дыстрыбуцыю Linux выбраць? Distro Picker гэта пошук дыстрыбуцый і кароткае апытаньне, якое падбірае пачаткоўцам патрэбную дыстрыбуцыю.

## Чаму некаторыя дыстрыбуцыі не даданыя

Гэтая аплікацыя не зьмяшчае ўсіх папулярных дыстрыбуцый (*як, Arch Linux, Ubuntu, Debian, NixOS, Gentoo, Void, Artix, Slackware, MX Linux, Manjaro, elementaryOS, Solus і г.д.*), карпаратыўных дыстрыбуцый (*як, Red Hat, AlmaLinux, Rocky Linux*) і спэцыялізаваных дыстрыбуцый (*як, Kali, Alpine*), бо яна прызначаная для пачаткоўцаў і мае на мэце спрасьціць выбар. Урэшце ж большасьць дыстрыбуцый Linux разьдзяляюць адныя самыя тэхналёґіі й падобныя адна да адной.

## Наколькі вялікі Linux?

Станам на сярэдзіну 2026 году ў сьвеце налічваецца прыблізна **100–120 мільёнаў** кампутараў і **60–75 мільёнаў** карыстачоў Linux (каля 25–30% зь іх выкарыстваюць Ubuntu, 10% Linux Mint, 5% Arch Linux і 4% Debian). Гэта рэпрэзэнтуе каля 4–5% рынку.

## Хто карыстаецца Linux'ам?

Да 70% карыстачоў Linux'а тэхнічна дасьведчаныя. Іншыя 15% гульцы, у той час як астатнія 15% гэта "нармалёвікі" (спачатны ўсталявальны бар’ер і патэнцыйныя перашкоды з Secure Boot / dual-boot часта замінаюць ім паспрабаваць Linux. Бальшыня "нармалёвікаў" нават ня ведаюць, чым ёсьць Linux).

## Парады наконт dual-boot

Усталюйце Linux на асобным дыску й не выкарыствайце прылады Windows для зьмяненьня памеру разьдзелаў на ім (нават ня зь Linux), бо Windows можа зрабіць Linux незапускальным.

## Secure Boot

Калі дыстрыбуцыя не падпірае Secure Boot, вам трэба вылучыць яго ў вашым BIOS перад яе ўсталяваньнем.

## Чаму Linux меней папулярны за Windows'а?

Linux не такі папулярны як Windows з колькіх галоўных прычын:

- Ён рэдка пастаўляецца перадусталяваным, і бальшыня карыстачоў мае схільнасьць датрымвацца стандартных опцый.
- Людзі прызвычаеныя да Windows'а. Гэта глыбока ўкаранёная звычка, і яны рэдка йдуць проці ўстанавёнага парадку.
- Горшая падпора праґрамнага й апаратнага забясьпечаньня. Гэта рэкурсыўны фактар: яна можа палепшыцца як Linux стане папулярнейшым, і гэта ўжо адбываецца.
- Ёсьць тэхнічныя бар’еры, сярод якіх BIOS, ручное ўсталяваньне, Secure Boot і праблемы з dual-boot, калі абнавеньне Windows'а можа зламаць Linux, і іншыя ўскладненьні.

Калі б Linux быў папярэдне ўсталяваны на ўсіх кампутарах вытворцамі (апрача адной кампаніі зы сваёй уласнай АС), ён бы ймаверна меў каля 70-80% рынку. Калі вытворцы абіраюць Windows сваёй стандартнай АС, яны страляюць сабе ў ногі, бо рабеньне Windows папулярнай і стандартнай дазваляе ёй дыктаваць, як вытворцы маюць рэалізаваць сваю апаратуру й BIOS. Гэта рэкурсыўная, самаразбуральная дынаміка, праз якую вытворцы дабравольна становяцца залежнымі ад Windows'а.

P.S. Шырокая даступнасьць выбару ня ёсьць праблемай. Калі адным днём зьявіцца 500 новых варыянтаў Windows'а, і ты ня будзеш пра іх ведаць, нічога для цябе ня зьменіцца; ты працягнеш карыстацца тым самым варыянтам. Калі ты даведаешся пра новыя опцыі, нічога ня зьменіцца таксама. Калі ты быў задаволены старым выбарам, няма патрэбы пералучацца на іншы. Псыхаляґічны цяжар выбару й жаданьне "ўжываць найлепшае" (кампульсыўнае захаваньне) гэта іншыя праблемы, што цалком залежаць ад складу мысьленьня чалавека; гэта не праблемы Linux'а. Бальшыня дыстрыбуцый Linux’а разьдзяляюць адныя самыя кампанэнты, таму яны болей падобныя да варыянтаў адной самай АС з рознымі стандартнымі опцыямі. Калі колькасьць дыстрыбуцый Linux’а штучна паменшыцца, дамінантная дыстрыбуцыя згаўніцца (як Ubuntu, толькі значна горш). Магчымасьць выбіраць дыстрыбуцыю дазваляе Linux'у абходзіць карпаратыўную прагнасьць і бюракратыю і абмінаць такія практыкі як вэрыфікацыя веку. Гэта таксама паказвае кірунак разьвіцьця, якому карыстачы аддаюць перавагу. Калі адна дыстрыбуцыя раптам стане значна лепшай за рэшту для бальшыні карыстачоў, яны натуральна пералучацца на яе; гэта ня мусіць кантралявацца ручна. Але тады людзі закладуць свае ўласныя дыстрыбуцыі на ёй, таму колькасьць дыстрыбуцый ня зьменшыцца. Існаваньне ўсіх гэтых дыстрыбуцый і сам факт таго, што людзі хочуць імі карыстацца, ужо ёсьць довадам іхнай патрэбнасьці само сабой.

## Рэкамэндаваныя праґрамы

- **Браўзэры**: Brave Origin (для прыватнасьці й блякаваньня рэклям), Helium (для прадукцыйнасьці й мінімалізму), Zen (для непаўторнага дызайну й вэртыкальных укладак), Floorp (для высокай наладжвальнасьці).
- **Офіс**: OnlyOffice, LibreOffice.
- **Торэнт-кліент**: qBittorrent.
- **Аналізатар дыска**: Filelight (KDE/Qt), Baobab (GNOME/GTK), gdu (тэрмінальная праграма, напісаная на Rust).
- **Лакальная Штучная Інтэліґенцыя**: LM Studio (раджу мадэль Mistral).

- **Запуск праґрам Windows**: Bottles, Winboat.
- **Ачысьнікі**: BleachBit, Stacer (не патрэбны для нязьменных сыстэм).
- **Рэзэрвовае капіяваньне**: Timeshift (не патрэбны для нязьменных сыстэм).
- **Альтэрнатыва для Nvidia Shadow Play**: GPU Screen Recorder.
- **Альтэрнатывы для Photoshop**: Photoshop online, Photopea, GIMP, Krita, Affinity (праз Bottles), Canva (для простых задач).
- **Альтэрнатыва для Lightroom**: Darktable.
- **Альтэрнатыва для Illustrator**: Inkscape.
- **Альтэрнатыва для Premier Pro**: DaVinci Resolve, Kdenlive.
- **Альтэрнатывы для Discord (акрамя афіцыйнай аплікацыі)**: Matrix/Element, Fluxer, Stoat.
- **Альтэрнатывы для Slack і Microsoft Teams (акрамя афіцыйных аплікацый)**: Rocket.chat, Mattermost, Matrix/Element, Zulip.
- **Альтэрнатыва для Zoom (акрамя афіцыйнай аплікацыі)**: Jitsi Meet.
