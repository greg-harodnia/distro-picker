# Вітаем у Выбарніку Дыстрыбуцыі

Ня ведаеце, якую дыстрыбуцыю Linux выбраць? Distro Picker гэта пошук дыстрыбуцый і кароткае апытаньне, якое падбірае пачаткоўцам патрэбную дыстрыбуцыю.

## Чаму некаторыя дыстрыбуцыі не даданыя

Гэтая аплікацыя не зьмяшчае ўсіх папулярных дыстрыбуцый (*як, Arch Linux, Ubuntu, Debian, NixOS, Gentoo, Void, Artix, Slackware, MX Linux, Manjaro, elementaryOS, Solus і г.д.*), карпаратыўных дыстрыбуцый (*як, Red Hat, AlmaLinux, Rocky Linux*) і спэцыялізаваных дыстрыбуцый (*як, Kali, Alpine*), бо яна прызначаная для пачаткоўцаў і мае на мэце спрасьціць выбар. Урэшце ж большасьць дыстрыбуцый Linux разьдзяляюць адныя самыя тэхналёґіі й падобныя адна да адной.

## Наколькі вялікі Linux?

Станам на сярэдзіну 2026 году ў сьвеце налічваецца прыблізна **100–120 мільёнаў** кампутараў і **60–75 мільёнаў** карыстачоў Linux (каля 25–30% зь іх выкарыстваюць Ubuntu, 10% Linux Mint, 5% Arch Linux і 4% Debian). Гэта рэпрэзэнтуе каля 4–5% рынку.

## Парады наконт dual-boot

Усталюйце Linux на асобным дыску й не выкарыствайце прылады Windows для зьмяненьня памеру разьдзелаў на ім (нават ня зь Linux), бо Windows можа зрабіць Linux незапускальным.

## Secure Boot

Калі дыстрыбуцыя не падпірае Secure Boot, вам трэба вылучыць яго ў вашым BIOS перад яе ўсталяваньнем.

## Рэкамэндаваныя праґрамы

- **Браўзэры**: Brave Origin (для прыватнасьці й блякаваньня рэклям), Helium (для прадукцыйнасьці й мінімалізму), Zen (для непаўторнага дызайну й вэртыкальных укладак), Floorp (для высокай наладжвальнасьці).
- **Офіс**: OnlyOffice, LibreOffice.
- **Торэнт-кліент**: qBittorrent.
- **Аналізатар дыска**: Filelight (KDE/Qt), Baobab (GNOME/GTK), gdu (тэрмінальная праграма, напісаная на Rust).
- **Лакальная Штучная Інтэліґенцыя**: LM Studio (раджу мадэль Mistral).
- **Пашыранае праграмнае забясьпечаньне**: Flatpak (Bazaar або ваш цэнтар ПЗ), Distrobox (DistroShelf для GNOME/GTK, Kontainer для KDE/Qt).
- **Запуск праґрам Windows**: Bottles, Winboat.
- **Ачысьнікі**: BleachBit, Stacer (не патрэбны для нязьменных сыстэм).
- **Рэзэрвовае капіяваньне**: Timeshift (не патрэбны для нязьменных сыстэм).
- **Альтэрнатыва для Nvidia Shadow Play**: GPU Screen Recorder.
- **Альтэрнатывы для Photoshop**: Photoshop online, Photopea, GIMP, Krita, Affinity (праз Bottles), Canva (для простых задач).
- **Альтэрнатыва для Lightroom**: Darktable.
- **Альтэрнатыва для Illustrator**: Inkscape.
- **Альтэрнатыва для Premier Pro**: DaVinci Resolve, Kdenlive.
- **Альтэрнатывы для Discord (акрамя афіцыйнай аплікацыі)**: Matrix/Element, Fluxer, Stoat.
- **Альтэрнатывы для Slack і Microsoft Teams (акрамя афіцыйных аплікацый)**: Rocket.chat, Mattermost, Matrix/Element, Zulip.
- **Альтэрнатыва для Zoom (акрамя афіцыйнай аплікацыі)**: Jitsi Meet.

### Карысныя інструмэнты

- **Ventoy** для стварэньня запусковай флэшкі з колькімі дыстрыбуцыямі Linux.
- **LocalSend** для хуткай перадачы даных праз лакальныя сеткі.
- **[Distrosea](https://distrosea.com/)** для тэсту разнародных дыстрыбуцый Linux анлайн.
