# Welcome to Distro Picker

Not sure which Linux distribution to use? Distro Picker is a distro finder and quick quiz built to match beginners with the right distro.

## Why some distributions aren't listed

The picker doesn't include other popular distributions (*like Arch Linux, Ubuntu, Debian, NixOS, Gentoo, Void, Artix, Slackware, MX Linux, Manjaro, elementaryOS, Solus, and so on*), enterprise-level distributions (*like Red Hat, AlmaLinux, Rocky Linux*) or niche distributions (*like Kali, Alpine*), as it's intended for complete beginners and aims to simplify the choice. At the end of the day, most Linux distributions share (distribute) the same technologies and are very similar.

## How big is Linux?

As of mid-2026, there are approximately **100–120 million** computers and **60–75 million** Linux users worldwide (around 25–30% of whom use Ubuntu, 10% Linux Mint, 5% Arch Linux, and 4% Debian). This represents about 4–5% of the market share.

## Who uses Linux?

Up to 70% of Linux users are technically skilled. Another 15% are gamers, while the rest 15% are "normies" (the initial installation barrier and potential Secure Boot / dual-boot issues usually prevent them from trying Linux. Most of the "normies" don't even know what Linux is).

## Dual-booting hints

Install Linux on a separate disk and don't use Windows tools to resize partitions on it (even non-Linux ones), as Windows can make Linux unbootable.

## Secure Boot

If a distribution doesn't support Secure Boot, you need to turn Secure Boot off in your BIOS before installing it.

## Why is Linux less popular than Windows?

Linux isn't as popular as Windows for several main reasons:

- It rarely comes preinstalled, and people tend to stick with the default option.
- People are accustomed to Windows. It's a deeply ingrained habit, and they rarely go against the established flow.
- Hardware and software support is poorer. This is a recursive factor: it can improve as Linux becomes more popular, and it is already happening.
- There are technical barriers, including the BIOS, manual installation, Secure Boot, and dual-boot problems when a Windows update breaks Linux, among other complications.

If Linux were preinstalled on all computers by manufacturers (except for the one company with its own OS), it would probably hold around 70–80% of the market share. When manufacturers choose Windows as their preinstalled OS, they shoot themselves in the foot: making Windows popular and the default allows it to dictate how manufacturers implement their hardware and BIOS. This is a recursive, self-destructive dynamic in which manufacturers voluntarily become dependent on Windows.

P.S. The broad availability of choice isn't a problem. If one day 500 new Windows variants are introduced and you don't know about them, nothing will change for you; you will still use the same variant. If you know about the new choices, nothing changes either. If you were happy with the old option, there is no need to switch to another. The psychological burden of choice and the desire to "use the best" (ADHD-like behaviour) are separate issues that depend entirely on a person's mindset; they aren't Linux issues. Most Linux distros share the same components, so they are more like variants of the same operating system with different default options. If the number of Linux distros were artificially reduced, the dominant distribution would become trash (like Ubuntu, but much worse). The ability to choose a distro allows Linux to circumvent corporate greed and bureaucracy and avoid practices such as age verification. It also shows which direction users prefer development to take. If one distro suddenly became much better than all the other options for the majority of users, they would naturally switch to it; this should not be controlled manually. But people would then base their own distros on it, so the number of distros would not decrease. The existence of all these distros—the fact that people choose to use them—is proof of their necessity in and of itself.
